# Consistent Vaulting

Consistent Vaulting now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Consistent Vaulting's C source is in
[`src/components/consistent_vaulting`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/consistent_vaulting).

The standalone Lua mod (v8.9.1 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/ConsistentVaulting/tree/legacy) branch. Its releases and tags are unchanged.
